# Client Media Shop

This is a React application for a client media shop that allows users to browse and view various media items.

## Project Structure

```
client-media-shop
├── public
│   └── index.html
├── src
│   ├── components
│   │   └── MediaItem.tsx
│   ├── pages
│   │   └── Home.tsx
│   ├── App.tsx
│   ├── index.tsx
│   └── types
│       └── index.ts
├── package.json
├── tsconfig.json
└── README.md
```

## Getting Started

To get started with the project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd client-media-shop
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm start
   ```

The application will be available at `http://localhost:3000`.

## Usage

- The main page of the application is the Home component, which displays a list of media items.
- Each media item is represented by the MediaItem component, which shows the title, description, and image.
